# Claims

Bright Line 14 sets one test for every claim: whoever reads it checks it against
shared evidence, rather than against your conviction. Two families of claim slip
that test often enough to earn their own instruments.

```sudolang
Claims {
  when (calling something ready, a foundation, a basis, a substrate, a slot,
        "in place", "already supports", or "anticipates" a next step) {
    read(../references/readiness-claims-reference.md)
    // the claim itself fires this wherever it appears, so it reaches inside
    // auditing, exploring, planning, designing, implementing, and reasoning
    // toward a decision
  }

  when (handing a reader a word that scores something:
        clean, plain, simple, idiomatic, better, "this matches that") {
    read(../references/evaluative-language.md)
    // binds at the handoff boundary; thinking you hold for yourself stays free
  }
}
```
